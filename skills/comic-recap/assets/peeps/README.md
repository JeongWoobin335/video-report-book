만화 캐릭터 파츠. [Open Peeps](https://www.openpeeps.com/) (Pablo Stanley) — **CC0**. 그림은 그대로이고, `body/Pointing Up.svg`만 손이 잘리지 않게 캔버스 폭을 818→900으로 넓혔다(`cast.json`의 `body_width`).
파일은 [jenshor/open-peeps](https://github.com/jenshor/open-peeps)의 `assets/atoms`에서 쓰는 것만 골라 옮겼다.

조립: 1000×1200 캔버스(viewBox `-75 0 1000 1200`)에 몸(818×733)을 (16, 467), 머리(473×567)를 (190, 40), 얼굴(289×293)을 (349, 226)에 놓는다.
몸 파츠는 포즈와 옷이 한 몸이다 — 그래서 `cast.json`에서 캐릭터마다 옷이 비슷한 몸만 묶어 두었다.
