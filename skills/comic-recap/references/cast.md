# 캐릭터와 표정

정확한 목록은 `assets/cast.json`이 기준이다. 아래는 고를 때 참고할 설명.

## 캐릭터

| id | 생김새 | 어울리는 역할 |
|---|---|---|
| `mentor` | 짧은 머리, 짙은 무늬 상의, 노란 후광 | 설명하는 사람 — 선배, 강사 역, 회의에 들어갔던 사람 |
| `newbie` | 앞머리 있는 중단발, 검은 티, 분홍 후광 | 묻는 사람 — 신입, 회의에 못 들어간 사람, 독자의 대리인 |
| `peer` | 올림머리에 머리띠, 밝은 셔츠, 초록 후광 | 세 번째 인물 — 다른 의견을 내는 동료, 두 번째 질문자 |

한 만화에 두 명이면 충분하다. `peer`는 꼭 필요할 때만.

그림은 Open Peeps(CC0) 파츠를 겹쳐 만든다(`assets/peeps/`). 이 그림체는 포즈와 옷이 한 파츠라서, 표정에 따라 포즈가 바뀌면 옷도 조금 달라진다 — 캐릭터마다 옷이 비슷한 포즈만 묶어 두었고(`cast.json`의 `bodies`), 머리 모양과 후광 색, 이름표로 누구인지 알아보게 한다.

## 표정

| 표정 | 모습 | 쓸 때 |
|---|---|---|
| `explain` | 말하는 입, 손가락을 세우거나 손짓 | 설명할 때 |
| `ask` | 가볍게 웃으며 손바닥을 펴 보임, 물음표 | 질문할 때 |
| `confused` | 걱정스러운 얼굴에 팔짱, 물음표 | 이해가 안 될 때, 틀린 짐작을 할 때 |
| `surprised` | 동그래진 눈, 느낌표, 컷에 집중선 | 반전, 몰랐던 사실 |
| `happy` | 활짝 웃음 | 이해했을 때, 마무리 |
| `worried` | 겁먹은 얼굴 | 문제 상황, 빠듯한 일정 |
| `think` | 곁눈질하며 생각, 말줄임표 | 듣고 생각할 때 |
| `neutral` | 기본 | 그 외 |
