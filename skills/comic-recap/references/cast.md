# 캐릭터와 표정

정확한 목록은 `assets/cast.json`이 기준이다. 아래는 고를 때 참고할 설명.

## 캐릭터

| id | 생김새 | 어울리는 역할 |
|---|---|---|
| `mentor` | 짙은 단발, 안경, 남색 상의 | 설명하는 사람 — 선배, 강사 역, 회의에 들어갔던 사람 |
| `newbie` | 갈색 짧은 머리, 주황 후드 | 묻는 사람 — 신입, 회의에 못 들어간 사람, 독자의 대리인 |
| `peer` | 검은 긴 머리, 초록 상의 | 세 번째 인물 — 다른 의견을 내는 동료, 두 번째 질문자 |

한 만화에 두 명이면 충분하다. `peer`는 꼭 필요할 때만.

## 표정

| 표정 | 모습 | 쓸 때 |
|---|---|---|
| `explain` | 입을 열고 한 팔로 가리킴 | 설명할 때 |
| `ask` | 입을 열고 손을 듦, 물음표 | 질문할 때 |
| `confused` | 한쪽 눈썹 올림, 물음표 | 이해가 안 될 때, 틀린 짐작을 할 때 |
| `surprised` | 큰 눈, 느낌표 | 반전, 몰랐던 사실 |
| `happy` | 웃는 눈 | 이해했을 때, 마무리 |
| `worried` | 처진 눈썹 | 문제 상황, 빠듯한 일정 |
| `think` | 손을 턱에, 말줄임표 | 듣고 생각할 때 |
| `neutral` | 기본 | 그 외 |
