# 교육·강의 영상 퀴즈

강의 퀴즈가 확인하려는 것은 "강사가 뭐라고 했는지 외웠나"가 아니라 **"배운 걸 써먹을 수 있나"**다. 그래서 `이해` 문항이 절반 이상이 되게 한다. 10문항이면 기억 4 : 이해 6 정도.

## 리포트의 어디서 문항이 나오는가

| 리포트 항목 | 문항 유형 | 비고 |
|---|---|---|
| `주의:` 항목 | 이해 | **가장 먼저 출제한다.** 강사가 직접 "여기서 헷갈린다"고 짚은 곳이고, 그 오해가 그대로 최고의 오답이 된다 |
| 비교 표 | 이해 | 표의 한 행을 묻고 다른 행의 내용을 오답으로 쓴다 |
| `예시:` 항목 | 이해 | 아래 "이해 문항 만드는 법" 참고 |
| 단계·순서 | 기억/이해 | "2단계 다음에 일어나는 일은?", "서버가 304를 돌려주는 것은 어떤 경우인가요?" |
| 핵심 개념(용어집) | 기억 | 용어 정의. 많아야 2~3문항 — 용어 암기 퀴즈가 되지 않게 |
| 학습 목표, 정리 | 직접 출제 안 함 | 어떤 내용이 중요한지 판단하는 기준으로만 쓴다 |

## 이해 문항 만드는 법

이해 문항은 개념을 **상황에 적용**하게 한다. 그런데 여기엔 함정이 있다: 상황을 새로 지어내면 영상에 없는 지식이 필요해질 수 있고, 그러면 영상을 다 본 사람도 틀린다. 그래서 상황은 **영상이 든 예시와 같은 구조**여야 한다.

- 강사의 예시를 뒤집어 묻는다. 강사가 "은행 거래 내역에는 `no-store`를 쓴다"고 했다면 → "은행 거래 내역처럼 민감한 응답에 적절한 설정은 무엇인가요?"
- 강사가 설명한 원리로 결과를 묻는다. "ETag가 같으면 304를 돌려준다"고 했다면 → "브라우저가 보낸 ETag가 서버의 것과 같을 때, 서버의 응답에는 무엇이 들어 있나요?"
- 강사가 말한 이유를 묻는다. "왜 해시가 들어간 파일은 캐시 기간을 길게 줘도 안전한가요?"

강사가 든 예시를 살짝 바꾸는 정도(로고 이미지 → 파비콘)는 괜찮지만, 영상이 다루지 않은 조건이 끼어드는 상황("CDN을 쓰는 경우에는?")은 안 된다. 판단 기준: *이 문항의 정답을 리포트 항목만으로 입증할 수 있는가?*

## 어조

학습자를 대하는 존댓말. 시험지 같은 "다음 중 ~을 고르시오"보다 "~는 무엇인가요?", "~하려면 어떻게 해야 하나요?"가 낫다.
